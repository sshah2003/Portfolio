# Sohil Shah — Portfolio

An interactive portfolio that rides the **DC Metro**. Nine real stations — Union
Station to Dulles — each one a chapter: work at The Washington Post, projects
(featuring [ClassMate](https://classmate-lemon.vercel.app/)), skills as transfer
lines, startup interests, teaching, and a timeline. A train tracks your scroll
along the route rail; every section reveals as you arrive.

Built with React 18 + Vite and Framer Motion: scroll-driven train progress, a
live "departures board," expandable station cards, a route-map overlay, and
full reduced-motion support.

## Develop

```sh
npm install
npm run dev      # local dev server
npm run build    # production build → dist/
npm run preview  # serve the production build
```
